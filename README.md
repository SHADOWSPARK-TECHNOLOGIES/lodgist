# Lodgist 🏠

**Proptech platform for property discovery, listing, and management.**
Live: https://lodgist.online

> Part of ShadowSpark Technologies — building practical tech for African real estate.

## What it does
- Property listings (rent / sale / short-let) across Nigerian cities
- Search & filter by location, price, type, bedrooms
- Landlord / agent dashboard + tenant inquiries
- Maps integration + virtual tours

## Stack
- Frontend: JavaScript / Next.js (see `package.json`)
- Deployed on Vercel

## Getting started
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Environment variables
Copy `.env.example` → `.env.local` and fill:
- `DATABASE_URL`
- Map provider token
- Auth secrets

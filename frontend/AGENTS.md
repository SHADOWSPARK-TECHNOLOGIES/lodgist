# Lodgist frontend rules

Live site is this directory, deployed to https://lodgist.online. Do not edit `lodgist/app/`. That tree is not the live site.

Public inventory is a home Lodgist has reviewed. Review is not "all checks passed." Payment never sets a badge or a Trust Score. Zero is not a score. An example figure is not a bill.

Do not invent a listing, phone, rent, photo, or testimonial. Do not scrape portals or Facebook into inventory. A social post is not permission.

`/nekede` may show an example card labeled not a home. Do not put that example in search.

Read `HANDOFF.md` and do only NOW. Overwrite HANDOFF.md when the task changes. Do not append.
